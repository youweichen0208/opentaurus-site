当前对外可见的完整 Tool 面

这一页不再只放几个例子，而是按真实注册代码展示 MCP 的完整能力。当前默认会注册 23 类能力中的大部分：基础 Tool、云上下文 Tool、diagnostics Tool 常驻；`execute_sql`、`explain_sql_enhanced`、`flashback_query`、recycle bin Tool 则按配置或 capability 条件出现。

Common / Discovery

默认基础工具

  • ping: 连通性 smoke test，返回 `pong`。
  • list_data_sources: 列出当前配置的 datasource profiles。
  • list_databases: 查看某 datasource 下的数据库。
  • list_tables: 查看某数据库下的表和视图。
  • describe_table: 查看列、索引、主键和引擎提示。
  • show_processlist: 用安全默认值查看当前会话与连接状态。
SQL Execution

查询与执行

  • execute_readonly_sql: 执行只读 SQL，带 guardrail。
  • explain_sql: 运行标准 EXPLAIN 并返回 plan 分析。
  • execute_sql: 执行变更 SQL，仅在显式开启 mutations 时暴露。
Capability / Cloud Context

Taurus 探测与云会话上下文

  • get_kernel_info: 判断实例是否为 TaurusDB，并返回内核元信息。
  • list_taurus_features: 返回 feature matrix，兼容非 TaurusDB。
  • set_cloud_region: 切换当前会话的华为云 region。
  • set_cloud_access_keys: 设置当前会话使用的 AK/SK。
  • list_cloud_taurus_instances: 列出当前云项目可见的 TaurusDB 实例。
  • select_cloud_taurus_instance: 选择默认实例，供 diagnostics 复用实例与节点上下文。
Diagnostics

默认注册的 8 个诊断工具

  • diagnose_service_latency: 从延迟、超时、CPU、连接增长切入定位根因。
  • diagnose_db_hotspot: 识别最热 SQL、表或会话。
  • find_top_slow_sql: 找出最可疑的慢 SQL。
  • diagnose_slow_query: 对单条 SQL 做更深的慢查询诊断。
  • diagnose_connection_spike: 诊断连接数激增。
  • diagnose_lock_contention: 诊断锁等待和阻塞。
  • diagnose_replication_lag: 诊断复制延迟与回放压力。
  • diagnose_storage_pressure: 诊断存储压力。
Dynamic Registration

按 capability 才会出现的 TaurusDB 专属 Tool

explain_sql_enhanced 当 `ndp_pushdown` 或 `parallel_query` 可用时注册。返回 TaurusDB-aware EXPLAIN，并带 NDP / PQ / OFFSET 优化提示。
flashback_query 当 `flashback_query` feature 可用时注册。用于按历史时间点执行只读 flashback SELECT。
list_recycle_bin 当 `recycle_bin` feature 可用时注册。用于恢复前的只读排查。
restore_recycle_bin_table 当 `recycle_bin` 可用且 mutations 开启时注册。恢复前必须显式确认。
Capability Probe

先探测，再决定暴露什么工具

不要把所有 TaurusDB 特性硬编码成静态卖点。更好的展示方式是让用户看到：不同内核、不同实例能力下，工具集会发生变化。

Diagnostics

诊断结果要展示“结论 + 下一步”

慢 SQL、锁、连接堆积不是简单列表。更适合展示的是：`diagnose_service_latency` 给出根因摘要，并指向下一步工具。

diagnostics
severity: high
summary: slow SQL plus connection buildup
next: diagnose_slow_query / show_processlist
Cloud Evidence

云端证据不是独立产品面，而是 MCP 证据源

CES、DAS、实例解析和 context export 更适合放在 MCP 页面里，因为它们本质上是在增强 MCP 的诊断上下文，而不是另一个单独入口。
