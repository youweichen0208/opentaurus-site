把接入文档独立出来

“如何在 Claude、Cursor、VS Code 里接入 MCP” 不应该埋在首页底部。它应该是单独页面，面向第一次配置 Agent 的用户。当前代码里已经实现的是 `@huaweicloud/taurusdb-mcp init`，而不是完整的 `taurusdb` companion CLI。

init client config
npx> @huaweicloud/taurusdb-mcp init --client claude
adds server: huaweicloud-taurusdb
command: npx -y @huaweicloud/taurusdb-mcp
Claude

已实现：`init --client claude`

{
  "mcpServers": {
    "huaweicloud-taurusdb": {
      "command": "npx",
      "args": ["-y", "@huaweicloud/taurusdb-mcp"]
    }
  }
}

macOS 默认写入 `~/Library/Application Support/Claude/claude_desktop_config.json`。Linux 默认写入 `~/.config/Claude/claude_desktop_config.json`。

Cursor / VS Code

已实现：`init --client cursor|vscode`

{
  "mcpServers": {
    "huaweicloud-taurusdb": {
      "command": "npx",
      "args": ["-y", "@huaweicloud/taurusdb-mcp"]
    }
  }
}
{
  "servers": {
    "huaweicloud-taurusdb": {
      "command": "npx",
      "args": ["-y", "@huaweicloud/taurusdb-mcp"]
    }
  }
}

Cursor 使用 `~/.cursor/mcp.json`，键名是 `mcpServers`。VS Code 使用用户级 `mcp.json`，键名是 `servers`。

当前可直接照做的接入步骤

1. 安装配置 `npx @huaweicloud/taurusdb-mcp init --client claude`、`cursor` 或 `vscode`
2. 配 profile 默认 profile 文件路径来自实现：`~/.config/taurusdb-mcp/profiles.json`，也可用环境变量覆盖。
3. 重启客户端 `init` 命令只写配置，不会热更新客户端中的 MCP server 列表。
4. 先做 smoke 当前仓库 README 已有 `init`。`taurusdb mcp smoke` 属于 companion CLI 目标形态，页面里应标为“规划中”。

关于 OpenCode

当前代码和测试里没有 OpenCode 专用 `init` 适配器，所以这个站点现在不应该把 OpenCode 写成“已内建支持”。更稳妥的写法是：后续补一个 OpenCode 页面，等你确认它的真实配置文件路径和 JSON 结构后再落地。

这个页面应该回答的问题

怎么装 当前入口是 `npx @huaweicloud/taurusdb-mcp`，`init` 已实现，server 名固定为 `huaweicloud-taurusdb`。
配到哪里 Claude、Cursor、VS Code 的配置文件路径和 JSON 根键并不相同，页面里应该按客户端分别说明。
怎么验 至少验证客户端里已经出现 `huaweicloud-taurusdb`，再让 Agent 发起一次 `tools/list` 或最小连接测试。
哪些是规划 `taurusdb init`、`mcp smoke`、`runbook`、`cloud validate` 当前主要存在于 README 与架构文档中，应标注为 companion CLI 路线图。
