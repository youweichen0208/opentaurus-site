Companion CLI

CLI 不是第二个 SQL 客户端

这一页只讲 companion CLI 在做什么：初始化配置、验证 MCP、执行 smoke、编排 runbook、导出上下文，而不是和 MCP 页面混写。需要注意的是，这一层目前主要还是设计目标，已落地的稳定入口仍然是 `@huaweicloud/taurusdb-mcp` 包本身。

taurusdb cli
taurusdb> mcp smoke --profile prod-ro
✓ server ok
✓ tools/list ok
✓ datasource probe ok
Init

生成配置

面向 Claude、Cursor、VS Code 或其他客户端生成 MCP 配置，降低初次接入成本。

Smoke

验证链路

一条命令验证 server、tools/list、profile 和 capability probe，适合联调与验收。

Runbook

编排诊断

把多次 MCP 调用收束成对人类更友好的报告，而不是要求每个人手工拼命令。

建议保留的 CLI 页面结构

当前已实现 `npx @huaweicloud/taurusdb-mcp init --client claude|cursor|vscode`，以及默认 `npx @huaweicloud/taurusdb-mcp` 直接启动 stdio MCP server。
规划中的验证 `taurusdb mcp smoke --profile prod-ro`，当前在 README / 架构文档里已定义，但不该在现网页里写成“已经发布”。
规划中的工具透传 `taurusdb mcp call diagnose_service_latency --input latency.json`，定位是调试和 CI，而不是给 DBA 的日常主入口。
规划中的报告导出 `taurusdb runbook latency --since 15m --report latency.md`，通过 MCP Tool 编排输出人类可读报告。
